# TechCalc Pro - Advanced Scientific Calculator

A feature-rich scientific calculator web application with a modern, responsive design and advanced mathematical capabilities.

![TechCalc Pro Screenshot](screenshot.png)

## Features

### Core Functionality
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Advanced mathematical functions (logarithms, powers, roots)
- Trigonometric functions with exact values for special angles
- Fraction/decimal conversion and display
- Memory functions (store, recall, clear)
- Engineering notation support

### Special Features
- Exact fraction representation for common values
- Special angle handling (0°, 30°, 45°, 60°, 90°, etc.)
- Support for mathematical constants (π, e)
- Advanced functions (factorial, reciprocal, square root)
- Parentheses support for complex expressions

### User Interface
- Modern, responsive design
- Dark/light mode support
- Animated button presses and particle effects
- Visual feedback for calculations
- Fraction/decimal mode toggle
- Basic/Advanced mode toggle
- Degrees/Radians toggle

### Technical Features
- Keyboard support
- Mobile device compatibility
- Touch screen support with haptic feedback
- Error handling and recovery
- Responsive layout for all screen sizes

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/scientific-calculator.git
```

2. Navigate to the project directory:
```bash
cd scientific-calculator
```

3. Open `index.html` in your web browser or serve using a local server:
```bash
# Using Python
python -m http.server

# Using Node.js
npx serve
```

## Usage

### Basic Operations
- Use number keys (0-9) for input
- Basic operators (+, -, ×, ÷) for arithmetic
- Press '=' or Enter to calculate
- Press 'AC' or Escape to clear
- Press '⌫' or Backspace to delete last input

### Advanced Functions
- Trigonometric functions (sin, cos, tan)
- Logarithms (log, ln)
- Powers and roots (x², √x)
- Constants (π, e)
- Memory functions (M+, M-, MR, MC)

### Mode Switching
- Toggle between basic and advanced modes
- Switch between degrees and radians
- Toggle fraction/decimal display
- Enable/disable engineering notation

### Keyboard Shortcuts
- Numbers and operators: Direct input
- Enter: Calculate result
- Escape: Clear all
- Backspace: Delete last input
- Shift: Access secondary functions
- Alpha: Access tertiary functions
